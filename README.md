## 🏗️ Engineering Approach

I care more about solving the right engineering problem than introducing technology for its own sake.

When designing or modifying software, I think about:

* How the system will evolve
* How changes affect existing functionality
* Where complexity belongs
* How failures behave in production
* Whether an abstraction solves a real problem
* Performance implications
* Database behavior
* Operational overhead
* Testing and observability
* Maintainability
* Whether another engineer can safely understand and modify the system later

I’m particularly comfortable entering unfamiliar or existing codebases, understanding how they actually work, identifying structural problems, and improving them incrementally.
